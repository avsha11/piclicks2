# 🔧 Admin Preview Image & Print Files Fix

## Issues Fixed

### 1. ✅ Broken Preview Image in Admin
**Problem**: Preview image showing as broken in admin order details
**Root Cause**: Incorrect asset path - was using `/storage/` instead of `storage/`
**Fix**: Updated `order-details.blade.php` line 248-250

**Before**:
```php
asset($orderData->design_collage_master->image_path ? '/storage/' . $orderData->design_collage_master->image_path : 'assets/images/collage-image.png')
```

**After**:
```php
asset($orderData->design_collage_master->image_path ? 'storage/' . $orderData->design_collage_master->image_path : 'assets/images/collage-image.png')
```

### 2. ✅ Broken JPG Files in Print Files Download
**Problem**: Downloaded ZIP contained broken JPG files instead of PNG print files
**Root Cause**: Download function was using `image_edited` (original images) instead of `image_with_bleed` (print files)
**Fixes Applied**:

#### A. Frontend Fix (`order-details.blade.php`):
- Changed from `item.image_edited` to `item.image_with_bleed`
- Added PNG extension enforcement
- Updated lines 450-457

**Before**:
```javascript
let imageUrl = `${baseUrl}/${item.image_edited}`;
let extension = item.image_edited.split('.').pop().toLowerCase();
let filename = `tile_${index + 1}.${extension}`;
```

**After**:
```javascript
// Use print files (image_with_bleed) instead of original images (image_edited)
let imageUrl = `${baseUrl}/${item.image_with_bleed}`;
let extension = item.image_with_bleed.split('.').pop().toLowerCase();
// Ensure PNG extension for print files
if (extension !== 'png') {
    extension = 'png';
}
let filename = `tile_${index + 1}.${extension}`;
```

#### B. Backend Fix (`OrderController.php`):
- Changed API response from `image_edited` to `image_with_bleed`
- Updated line 275

**Before**:
```php
$images[] = ['image_edited' => $image];
```

**After**:
```php
$images[] = ['image_with_bleed' => $image];
```

## 🔍 Technical Details

### Data Flow
```
Editor → Save Collage → Generate Print Files → Store in image_with_bleed
                ↓
Admin Order Details → Download Button → API Call → Return Print Files → ZIP Download
```

### Print Files Generation
- Print files are generated by `PrintFileService` when collage is saved
- Files are stored as JSON array in `image_with_bleed` field
- Each file includes filters, text overlays, and proper dimensions
- Files are saved as PNG format with high quality
